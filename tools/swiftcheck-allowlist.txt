# swiftcheck reports any capitalised name called like a constructor that is
# neither declared in Arch/ nor listed here. That is the check that catches a
# SwiftUI view which was invented rather than written: a view used in view
# position is a bare type name, so the member check sees nothing to resolve and
# reports nothing. Two such views were written before this existed.
#
# Adding a name here is a claim that Apple declares it. If you are adding one
# because a check failed, make sure that is actually true.
